    🔗 Integratsiyalar

    Kalitlar shifrlangan holda faqat shu kompyuterda saqlanadi.

    🟦 JiraVazifalarni JQL bo'yicha yuklab olish O'chirilgan
    Sozlash:
    1. Atlassian API token yarating — id.atlassian.com
    2. Manzil: https://kompaniya.atlassian.net
    3. Email — Jira hisobingiz emaili, token — yuqorida yaratilgani
    ⬛ NotionHisobotni Notion sahifasi sifatida yuborish O'chirilgan
    Sozlash:
    1. Integratsiya yarating — notion.so/my-integrations, "Internal Integration Secret"ni nusxalang
    2. Hisobot saqlanadigan Notion sahifasini oching → ••• → Connections → integratsiyangizni qo'shing
    3. O'sha sahifaning havolasini quyidagi maydonga qo'ying
    🟪 ConfluenceHisobotni Confluence sahifasi sifatida yuborish O'chirilgan
    Sozlash:
    1. Atlassian API token — id.atlassian.com
    2. Manzil: https://kompaniya.atlassian.net/wiki
    3. Space Key — Confluence'da space sozlamalarida ko'rinadi (masalan HR)
    📥 Boshqa tizimlarTrello, Asana, Todoist, ClickUp — CSV orqali import CSV / JSON
    Task menejeringizdan vazifalarni CSV holida eksport qiling va quyiga qo'ying yoki faylni tanlang. Tizim title / name / task ustunini vazifa nomi, estimate / duration ustunini vaqt bahosi sifatida taniydi.

    🔑 Kirish usullari (tizim egasi uchun)

    Google va GitHub orqali kirishni yoqish uchun o'z OAuth ilovangiz ma'lumotlarini kiriting.

    🔵 GoogleGoogle hisobi bilan kirish O'chirilgan
    1. console.cloud.google.com → Credentials → Create OAuth client ID → Web application
    2. Authorized redirect URI maydoniga quyidagini qo'ying:
      http://127.0.0.1:4123/api/auth/callback/google
    ⬛ GitHubGitHub hisobi bilan kirish O'chirilgan
    1. github.com/settings/developers → New OAuth App
    2. Authorization callback URL:
      http://127.0.0.1:4123/api/auth/callback/github
