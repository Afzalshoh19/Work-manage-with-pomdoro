    Pochta serveri (tizim egasi uchun)

    Ro'yxatdan o'tishda emailga tasdiqlash kodi yuborilishi uchun kerak. Sozlanmasa tizim ishlashda davom etadi — kod server jurnaliga yoziladi.

    Gmail uchun qanday sozlanadi
    1. Google hisobingizda ikki bosqichli tasdiqlash yoqilgan bo'lishi kerak
    2. myaccount.google.com/apppasswords — «Ilova kaliti» (App password) yarating
    3. Host: smtp.gmail.com, Port: 587, Ulanish: STARTTLS
    4. Foydalanuvchi — Gmail manzilingiz, parol — yaratilgan 16 belgili ilova kaliti

    Kirish usullari (tizim egasi uchun)

    Google va GitHub orqali kirishni yoqish uchun o'z OAuth ilovangiz ma'lumotlarini kiriting.

    🔵 GoogleGoogle hisobi bilan kirish O'chirilgan
    1. console.cloud.google.com → Credentials → Create OAuth client ID → Web application
    2. Authorized redirect URI maydoniga quyidagini qo'ying:
      http://127.0.0.1:4123/api/auth/callback/google
    ⬛ GitHubGitHub hisobi bilan kirish O'chirilgan
    1. github.com/settings/developers → New OAuth App
    2. Authorization callback URL:
      http://127.0.0.1:4123/api/auth/callback/github
